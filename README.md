# نظام مجلس الاعتماد الأكاديمي وضمان جودة التعليم العالي - اليمن (CAQA Yemen)

نظام إلكتروني وطني لإدارة وحوكمة عمليات الاعتماد الأكاديمي وضمان الجودة لمؤسسات التعليم العالي والبرامج الأكاديمية في الجمهورية اليمنية.

## المميزات الأساسية:
- مساران مستقلان تماماً:
  1. مسار الاعتماد المؤسسي (Institutional Accreditation)
  2. مسار الاعتماد البرامجي (Programmatic Accreditation)
- تغطية دورة العمل الإجرائية الـ 7 مراحل:
  1. مرحلة التهيئة والدراسة الذاتية ورفع الأدلة والشواهد
  2. الفحص المكتبي الأولي والتحقق من الاستيفاء
  3. تشكيل لجان المراجعة الخارجية وجدولة الزيارة
  4. إدارة الزيارة الميدانية (المعامل، القاعات، المقابلات، أعمال الطلاب)
  5. مسودة التقرير، حق الرد للمؤسسة، والتقرير النهائي
  6. اتخاذ قرار المجلس، وإصدار شهادة الاعتماد الرسمية المزودة برمز QR
  7. المتابعة الدورية السنوية والزيارات الاستطلاعية
